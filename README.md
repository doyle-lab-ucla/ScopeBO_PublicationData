# ScopeBO_PublicationData
Publication data for the [ScopeBO paper](https://doi.org/10.1021/jacs.6c10981).

Citation: Roediger, S.; Sigman, M. S.; Doyle, A. G. *J. Am. Chem. Soc.* **2026**, *148* (37), 39911–39922.

* The ScopeBO algorithm can be found [here](https://github.com/doyle-lab-ucla/ScopeBO).

* To run the notebooks, please also download ScopeBO itself.
